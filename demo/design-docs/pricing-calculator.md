# Pricing Calculator

A small web tool a salesperson opens on a call: pick a configuration, see the
price, send the quote.

```project
name: Pricing Calculator
category: software
budget: 40
areas:
  - Configurator: the chair options, and which combinations are impossible
  - Pricing: volume breaks, regional adjustments, the approval threshold
  - Quote: a shareable link, and a PDF that survives being forwarded
```

## Constraints

- Works on a phone, because half of these calls happen in a car park.
- No login for the first version.
